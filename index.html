Flexbox Reference

Container Properties

  • display: flex; - Creates a flex container
  • flex-direction: row|column|row-reverse|column-reverse;
  • justify-content: flex-start|flex-end|center|space-between|space-around;
  • align-items: flex-start|flex-end|center|baseline|stretch;
  • flex-wrap: nowrap|wrap|wrap-reverse;

Item Properties

  • order: number;
  • flex-grow: number;
  • flex-shrink: number;
  • align-self: auto|flex-start|flex-end|center|baseline|stretch;

How to Play

Game Objective

Help the frogs reach their lily pads by writing CSS Flexbox code! Each level presents a layout challenge that you solve by applying the correct Flexbox properties.

Getting Started

  1. Read the level description to understand the goal
  2. Write CSS in the editor to position the frogs
  3. Click "Run" to see your changes
  4. When the frogs match the target layout, you'll advance!

Tips & Tricks

  • Start with display: flex; on the container
  • Use the reference guide for property syntax
  • If stuck, click the hint button for help
  • Experiment with different values to see their effects

Did You Know?

Flexbox Froggy is a great way to learn CSS layout techniques that are used in real-world web development. The skills you learn here will help you build better websites!
