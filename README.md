# Flexbox Froggy

Flexbox Froggy is an interactive game designed to teach the basics of CSS Flexbox in a fun and engaging way. Players help Froggy and friends by writing CSS code to align and distribute items within a container. Each level introduces a new Flexbox concept, making it an excellent resource for beginners and a refresher for experienced developers.

Visit [Flexbox Froggy](https://utl-shadab.github.io/flexbox-froggy-clone/) to start learning!
